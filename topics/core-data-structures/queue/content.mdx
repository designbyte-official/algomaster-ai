# Queue

> [!NOTE]
> **Core Concept**: A **Queue** is a linear data structure that follows the **FIFO** (First-In, First-Out) principle. Think of a line at a coffee shop: the first person to join the line is the first one served.

Queues are essential for managing resources where fairness or order matters, such as printer jobs, CPU task scheduling, or breadth-first search in graphs.

## Core Operations

| Operation | Description | Time Complexity |
|-----------|-------------|-----------------|
| `enqueue(x)` | Add element `x` to the rear | **O(1)** |
| `dequeue()` | Remove and return the front element | **O(1)** |
| `front()` | View the front element without removing it | **O(1)** |
| `isEmpty()` | Check if the queue is empty | **O(1)** |

> [!WARNING]
> **Performance Pitfall**: In JavaScript (and Python lists), using `shift()` or `pop(0)` to dequeue is **O(n)** because all subsequent elements must be shifted. For true **O(1)** performance, use a **Doubly Linked List** or a dedicated **Deque** class.

## Implementation

### Optimized Queue (using Object/Map)

```multi
[javascript]
class Queue {
    constructor() {
        this.items = {};
        this.frontIndex = 0;
        this.rearIndex = 0;
    }
    
    // O(1)
    enqueue(item) {
        this.items[this.rearIndex] = item;
        this.rearIndex++;
    }
    
    // O(1) - No shifting required
    dequeue() {
        if (this.isEmpty()) return null;
        
        const item = this.items[this.frontIndex];
        delete this.items[this.frontIndex];
        this.frontIndex++;
        
        // Reset indices if empty to prevent integer overflow (in theory)
        if (this.isEmpty()) {
            this.frontIndex = 0;
            this.rearIndex = 0;
        }
        
        return item;
    }
    
    // O(1)
    front() {
        if (this.isEmpty()) return null;
        return this.items[this.frontIndex];
    }
    
    isEmpty() {
        return this.rearIndex === this.frontIndex;
    }
    
    size() {
        return this.rearIndex - this.frontIndex;
    }
}
[python]
from collections import deque

class Queue:
    def __init__(self):
        # Python's deque is implemented as a doubly linked list
        self.items = deque()
    
    def enqueue(self, item):
        """Add to right - O(1)"""
        self.items.append(item)
    
    def dequeue(self):
        """Remove from left - O(1)"""
        if self.is_empty():
            raise IndexError("Dequeue from empty queue")
        return self.items.popleft()
    
    def front(self):
        if self.is_empty():
            raise IndexError("Queue is empty")
        return self.items[0]
    
    def is_empty(self):
        return len(self.items) == 0
        
    def size(self):
        return len(self.items)
[java]
import java.util.LinkedList;
import java.util.Queue;

public class QueueExample {
    public static void main(String[] args) {
        // LinkedList implements Queue interface
        Queue<Integer> queue = new LinkedList<>();
        
        // Add (Enqueue)
        queue.offer(1); // Safer than add()
        queue.offer(2);
        
        // Remove (Dequeue)
        System.out.println(queue.poll()); // 1, or null if empty
        
        // Peek (Front)
        System.out.println(queue.peek()); // 2, or null if empty
    }
}
[cpp]

    return 0;
}
```

## Types of Queues

### 1. Circular Queue (Ring Buffer)
Uses a fixed-size array and wraps around indices. Efficient for buffering data streams.

### 2. Priority Queue
Elements are dequeued based on **priority** rather than insertion order.
*   **Implementation**: Binary Heap
*   **Enqueue**: O(log n)
*   **Dequeue**: O(log n)

### 3. Deque (Double-Ended Queue)
Allows insertion and removal from **both** ends.

## Common Algorithmic Patterns

### 1. Moving Average from Data Stream
Calculate the average of the last `k` elements.

```javascript
class MovingAverage {
    constructor(size) {
        this.size = size;
        this.queue = [];
        this.sum = 0;
    }
    
    next(val) {
        this.queue.push(val);
        this.sum += val;
        
        if (this.queue.length > this.size) {
            this.sum -= this.queue.shift(); // Using simple array for clarity
        }
        
        return this.sum / this.queue.length;
    }
}
```

### 2. Breadth-First Search (BFS)
The most common application of queues in algorithms.
*   **Time**: O(V + E)
*   **Space**: O(V)

> **Strategy**: Explore neighbors layer by layer. Push starting node to queue. While queue not empty: dequeue node, process it, enqueue unvisited neighbors.
