# Stack

> [!NOTE]
> **Core Concept**: A **Stack** is a linear data structure that follows the **LIFO** (Last-In, First-Out) principle. Imagine a stack of cafeteria trays: you take the top one off first, which was the last one put on.

Stacks are fundamental to computer science, powering everything from function calls (recursion) to the "Undo" button in your text editor.

## Core Operations

| Operation | Description | Time Complexity |
|-----------|-------------|-----------------|
| `push(x)` | Add element `x` to the top | **O(1)** |
| `pop()` | Remove and return the top element | **O(1)** |
| `peek()` | View the top element without removing it | **O(1)** |
| `isEmpty()` | Check if the stack is empty | **O(1)** |

> [!TIP]
> **Stack Overflow**: This famously occurs when you push too many items onto the call stack (e.g., infinite recursion), exceeding the allocated memory limit.

### Array-based Implementation

```multi

class Stack {
    constructor() {
        this.items = [];
    }
    
    // O(1)
    push(element) {
        this.items.push(element);
    }
    
    // O(1)
    pop() {
        if (this.isEmpty()) return "Underflow";
        return this.items.pop();
    }
    
    // O(1)
    peek() {
        return this.items[this.items.length - 1];
    }
    
    isEmpty() {
        return this.items.length === 0;
    }
}

class Stack:
    def __init__(self):
        self.items = []
        
    def push(self, item):
        """Append to end of list (O(1))"""
        self.items.append(item)
        
    def pop(self):
        """Remove from end of list (O(1))"""
        if self.is_empty():
            raise IndexError("Pop from empty stack")
        return self.items.pop()
        
    def peek(self):
        if self.is_empty():
            raise IndexError("Peek from empty stack")
        return self.items[-1]
        
    def is_empty(self):
        return len(self.items) == 0
[java]
import java.util.EmptyStackException;

public class Stack<T> {
    private static class Node<T> {
        private T data;
        private Node<T> next;
        
        public Node(T data) {
            this.data = data;
        }
    }
    
    private Node<T> top;
    
    public void push(T data) {
        Node<T> node = new Node<>(data);
        node.next = top;
        top = node;
    }
    
    public T pop() {
        if (top == null) throw new EmptyStackException();
        T data = top.data;
        top = top.next;
        return data;
    }
    
    public T peek() {
        if (top == null) throw new EmptyStackException();
        return top.data;
    }
    
    public boolean isEmpty() {
        return top == null;
    }
}

#include <vector>

template <typename T>
class Stack {
private:
    std::vector<T> items;

public:
    void push(T item) {
        items.push_back(item);
    }
    
    T pop() {
        if (isEmpty()) throw std::out_of_range("Stack Underflow");
        T item = items.back();
        items.pop_back();
        return item;
    }
    
    T peek() {
        if (isEmpty()) throw std::out_of_range("Stack is empty");
        return items.back();
    }
    
    bool isEmpty() {
        return items.empty();
    }
```

## Common Algorithmic Patterns

### 1. Valid Parentheses
The quintessential stack problem.
*   **Time**: O(n)
*   **Space**: O(n)

> **Strategy**: Push opening brackets `(`, `[`, `{`. When you see a closing bracket, check if it matches the `top` of the stack. If yes, `pop()`; if no, it's invalid.

```javascript
function isValid(s) {
    const stack = [];
    const map = { ')': '(', '}': '{', ']': '[' };
    
    for (const char of s) {
        if (!map[char]) {
            stack.push(char); // Open bracket
        } else if (stack.pop() !== map[char]) {
            return false; // Mismatch or empty stack
        }
    }
    return stack.length === 0;
}
```

### 2. Monotonic Stack
Used to find the "Next Greater Element" or "Previous Smaller Element".
*   **Time**: O(n)
*   **Space**: O(n)

> **Strategy**: Maintain a stack that is always sorted (increasing or decreasing). When a new element breaks the order, pop elements until order is restored.
