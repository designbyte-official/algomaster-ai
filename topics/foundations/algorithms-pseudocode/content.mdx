# Algorithms & Pseudocode: The Blueprints of Logic

Before a single line of code is written, a developer must solve the problem in their head. That solution is an **Algorithm**. To describe that algorithm without getting bogged down in programming syntax, we use **Pseudocode**.

Think of a **Coffee Machine**:
1. **Input**: Coffee beans, water, and a button press.
2. **Algorithm**: 
   - Grind the beans.
   - Heat the water to 90°C.
   - Pass water through the grounds.
3. **Output**: A hot cup of coffee.

An algorithm is simply a step-by-step recipe for your computer.

---

## Characteristics of a Good Algorithm

Not every set of steps is a "good" algorithm. To be effective, it should be:

| Property | Description |
| :--- | :--- |
| **Finite** | It must eventually stop. No infinite loops. |
| **Definite** | Each step must be clear and unambiguous. |
| **Input/Output** | It should take some data and produce a result. |
| **Effective** | Every step must be basic enough to be carried out. |

---

## The Design Process

Moving from a problem to a working program follows a structured path.

![The Algorithm Design Process](/images/docs/algorithm_design_process.png)

1.  **Understand**: What exactly are we trying to solve?
2.  **Identify Input/Output**: What do we have, and what do we need?
3.  **Step-by-Step Logic**: Break it down into the smallest possible tasks.
4.  **Pseudocode**: Write the logic in plain English-like structure.
5.  **Implementation**: Translate the pseudocode into a real language like Python or Java.

## Example 1: Add Two Numbers (The Basics)

### Pseudocode
```text
START
    DECLARE num1, num2, sum
    INPUT num1, num2
    SET sum = num1 + num2
    PRINT "The result is: " + sum
END
```

```multi
[javascript]
const readline = require('readline').createInterface({
  input: process.stdin,
  output: process.stdout
});

readline.question('Enter num1: ', num1 => {
  readline.question('Enter num2: ', num2 => {
    const sum = Number(num1) + Number(num2);
    console.log(`The result is: ${sum}`);
    readline.close();
  });
});

[python]
num1 = int(input("Enter num1: "))
num2 = int(input("Enter num2: "))
total = num1 + num2
print(f"The result is: {total}")

[java]
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter num1: ");
        int n1 = sc.nextInt();
        System.out.print("Enter num2: ");
        int n2 = sc.nextInt();
        System.out.println("The result is: " + (n1 + n2));
    }
}

[cpp]
#include <iostream>
using namespace std;

int main() {
    int n1, n2;
    cout << "Enter num1: ";
    cin >> n1;
    cout << "Enter num2: ";
    cin >> n2;
    cout << "The result is: " << (n1 + n2) << endl;
    return 0;
}
```

## Example 2: Find Maximum (Decision Logic)

### Pseudocode
```text
IF a > b THEN
    PRINT a + " is larger"
ELSE IF b > a THEN
    PRINT b + " is larger"
ELSE
    PRINT "Both are equal"
ENDIF
```

```multi
[javascript]

if (a > b) {
    console.log(`${a} is larger`);
} else if (b > a) {
    console.log(`${b} is larger`);

    console.log("Both are equal");
}
```

## Example 3: Factorial (Recursion vs. Loops)

### Pseudocode (Recursive)
```text
FUNCTION factorial(n)
    IF n <= 1 THEN RETURN 1
    ELSE RETURN n * factorial(n - 1)
END FUNCTION
```

```multi
[javascript]
function factorial(n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
console.log("5! is:", factorial(5));

[python]
def factorial(n):
    if n <= 1: return 1
    return n * factorial(n - 1)

print(f"5! is: {factorial(5)}")

[java]
public class Main {

        return n * factorial(n - 1);
    }
    public static void main(String[] args) {
        System.out.println("5! is: " + factorial(5));
    }
}
```

## Standard Logic Patterns

Most algorithms are composed of these four recurring patterns.

![Standard Logic Patterns](/images/docs/pseudocode_logic_patterns.png)

1.  **Counting**: Incrementing a value based on a condition.
2.  **Accumulating**: Summing up values (e.g., total price in a cart).
3.  **Finding (Searching)**: Looking for a specific item in a list.
4.  **Transforming (Map)**: Changing every item in a list (e.g., converting all names to uppercase).

## Example 4: Linear Search (Finding an Item)

This involves checking every item in a list one by one until you find what you're looking for.

### Pseudocode
```text
FUNCTION linearSearch(list, target)
    FOR each item in list:
        IF item == target THEN RETURN "Found"
    ENDFOR
    RETURN "Not Found"
END FUNCTION
```

```multi
[javascript]
function linearSearch(arr, target) {
    for (let i = 0; i < arr.length; i++) {
        if (arr[i] === target) return i;
    }
    return -1;
}
const numbers = [10, 20, 30, 40, 50];
console.log("Found at index:", linearSearch(numbers, 30));

[python]
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target: return i
    return -1

numbers = [10, 20, 30, 40, 50]
print(f"Found at index: {linear_search(numbers, 30)}")

[java]
public class Main {
    static int linearSearch(int[] arr, int target) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == target) return i;
        }
        return -1;
    }
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40, 50};
        System.out.println("Found at index: " + linearSearch(numbers, 30));
    }
}

[cpp]
#include <iostream>
#include <vector>
using namespace std;

int linearSearch(vector<int> arr, int target) {
    for (int i = 0; i < arr.size(); i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

int main() {
    vector<int> numbers = {10, 20, 30, 40, 50};
    cout << "Found at index: " << linearSearch(numbers, 30) << endl;
    return 0;
}
```

## Example 5: Binary Search (Effeciency)

Binary search is much faster but only works on **sorted** lists. It works by repeatedly dividing the search interval in half.

### Pseudocode
```text
WHILE left <= right DO
    SET mid = (left + right) / 2
    IF list[mid] == target THEN RETURN mid
    ELSE IF list[mid] < target THEN SET left = mid + 1
    ELSE SET right = mid - 1
ENDWHILE
```

```multi
[javascript]
function binarySearch(arr, target) {
    let left = 0, right = arr.length - 1;
    while (left <= right) {
        let mid = Math.floor((left + right) / 2);
        if (arr[mid] === target) return mid;
        if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
const sortedNumbers = [10, 20, 30, 40, 50];
console.log("Binary Search Index:", binarySearch(sortedNumbers, 40));

[python]
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target: return mid
        elif arr[mid] < target: left = mid + 1
        else: right = mid - 1
    return -1

sorted_numbers = [10, 20, 30, 40, 50]
print(f"Binary Search Index: {binary_search(sorted_numbers, 40)}")

[java]
public class Main {
    static int binarySearch(int[] arr, int target) {
        int left = 0, right = arr.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (arr[mid] == target) return mid;
            if (arr[mid] < target) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
    public static void main(String[] args) {
        int[] sortedNumbers = {10, 20, 30, 40, 50};
        System.out.println("Binary Search Index: " + binarySearch(sortedNumbers, 40));
    }
}

[cpp]
#include <iostream>
#include <vector>
using namespace std;

int binarySearch(vector<int> arr, int target) {
    int left = 0, right = arr.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}

int main() {
    vector<int> sortedNumbers = {10, 20, 30, 40, 50};
    cout << "Binary Search Index: " << binarySearch(sortedNumbers, 40) << endl;
    return 0;
}
```

## Key Takeaways
- **Algorithms** are logic blueprints; **Code** is the construction.
- Use **Pseudocode** to plan without worrying about semi-colons or braces.
- Always check if your algorithm is **Finite** and **Definite**.
- Break complex problems into the **Standard Logic Patterns**.
